# Teste
CAMPOS GERAIS — SITE DIVIDIDO EM PÁGINAS

Arquivos:
- index.html: página inicial
- sobre.html: sobre a empresa, diferenciais e como funciona
- servicos.html: serviços
- produtos.html: produtos
- avaliacoes.html: avaliações e perguntas frequentes
- contato.html: contato e chamada para WhatsApp
- style.css: estilos compartilhados e layout responsivo

Como usar:
1. Extraia todos os arquivos para a mesma pasta.
2. Abra a pasta no VS Code.
3. Abra index.html no navegador (ou use a extensão Live Server).
4. Não mova o style.css para outra pasta, pois todas as páginas dependem dele.

Observação: mantive as informações, o telefone, endereço e textos presentes no HTML enviado. Confira os dados e as avaliações com a empresa antes de publicar.
